PII Reports add-on required

The open-source redibis core produces scan artifacts (pii_report.json). The filtered KPI console, CSV downloads, and compute debug stream ship as the commercial package redibis-reports.

Install into this environment
pip install redibis-reports
# or editable (monorepo):
#   pip install -e ./enterprise/addons/reports

# then restart the webapp and reopen /reports

See README.md#commercial-reporting for the public package boundary and installation summary.
