Find personal data, check quality, and publish trusted data contracts.

redibis is an open-source tool that looks at your tabular data, finds personal information (PII), checks data quality, and writes the result down as a data contract your team can review, trust and share. Everything runs on your own machine or servers.

What is redibis?

Point redibis at a CSV or Parquet file. It profiles every column, detects personal data such as names, phone numbers, emails and national IDs, and checks quality rules.

The findings become one versioned data contract in the open ODCS v3 format. People review and correct it, and their decisions are remembered on the next scan.

When you need to share the data, redibis can mask, hash, encrypt or replace sensitive values with realistic fakes first.

Quick start

  1. Clone the redibis repository from GitHub and open a terminal in it.
  2. Install redibis in a virtual environment:
    python3 -m venv .venv && source .venv/bin/activate && pip install -e ".[dev,web]" -c requirements/constraints.txt
  3. Start the dashboard, then open http://127.0.0.1:8000/
    ./scripts/webapp.sh --start
  4. Log in. A fresh install creates admin / admin — change that password straight away under Users.
  5. On the scan page, upload a CSV (or pick the sample tests/data/realistic_eshop_customer_account.csv) and press Scan.
  6. Open Contracts to see the contract created for your table.

Reading your results

Each column shows whether it holds personal data, what kind (for example PHONE_NUMBER or EMAIL_ADDRESS), how sensitive it is, and which detection engines agreed.

The profile panel shows null rate, distinct values, type and format. Quality results show which rules passed or failed.

Nothing is final until a person approves it: detections are suggestions.

Steward Review

Contracts → Steward Review walks you through the contract column by column. Accept a finding, correct it, or mark it for review.

Verified decisions are locked in: the next scan will not overwrite what a person confirmed.

Reviewing never starts a new scan, so it is safe to explore.

Masking and safe export

Data → Mask & Export suggests a rule per column: keep, redact, mask, hash, encrypt, format-preserving encryption (FF3-1) or realistic fakes (names, phones, emails, dates, social profile links and more).

The same input always gets the same fake, so joins across tables still work.

The risk panel warns about weak choices before you export. Keys never leave the run.

Business definitions with an LLM (optional)

Contracts → Enrich can draft column definitions and glossary terms using an LLM provider you configure in Settings, including models you host yourself.

Drafts are suggestions for a person to accept. The model can see column details and a few sample values, so use a provider you trust with your data — or one you host yourself.

Command line and API

Everything in the dashboard is also available from the redibis command (run redibis --help) and the HTTP API (open API Docs after logging in).

  1. Example: scan a file for personal data and save the contract.
    redibis scan data.csv shop.customers --mode pii --automerge pii --output-dir ./reports
